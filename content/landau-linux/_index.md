# ⚛️ LANDAU Linux

---

## 🎯 О проекте

LANDAU Linux - это **upstream-first форк** ядра Linux, исправляющий и
расширяющий его функционал:

*   🔄 **Регулярное обновление:** Следование за актуальными версиями ядра Linux
(раз в 2+ месяца).
*   📦 **Приём патчей:** Включение полезных наработок, которые по разным
причинам не попали в оригинальный репозиторий ядра Linux (драйверы,
архитектурные доработки).
*   🖥️ **Поддержка специализированной аппаратуры:** Создание единой ветки ядра
как основы BSP для процессоров различных архитектур (ARM, MIPS, RISC-V,
Эльбрус), аппаратных платформ, потребительской электроники, в том числе
разрабатываемой в России.
*   👁️ **Прозрачность:** Открытый процесс ревью, современный CI и совместное
тестирование.

Проект решает текущие задачи индустрии: сохраняет и развивает код ядра, борется
с его фрагментацией, а за счет консолидации открытых решений создает синергию
для всех, кто использует Linux в качестве системного ПО. В долгосрочной
перспективе LANDAU Linux станет надежной основой для разработчиков IP-ядер,
ODM-производителей, создателей дистрибутивов и других участников экосистемы.
