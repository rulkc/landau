# landau-hacker – тема для Hugo сайта LANDAU

**landau-hacker** – это адаптация темы [Hacker](https://github.com/pages-themes/hacker) от GitHub Pages под движок [Hugo](https://gohugo.io/). Тема используется на официальном сайте проекта [LANDAU](https://landau.one).

## Особенности

- Минималистичный «технический» дизайн с зелёным акцентом.
- Тёмный фон, моноширинные шрифты.
- Адаптивная вёрстка, поддержка относительных ссылок (`relativeURLs`).
- Встроенные архетипы для **новостей** и **событий**.
- Страница 404 в стиле темы.

## Установка

### 1. Скопировать тему в проект

```bash
git clone https://gitflic.ru/project/maquefel/landau-hacker themes/landau-hacker
```
